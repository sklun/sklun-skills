# TLQ 项目参考

以下为此次 TLQ 部署标准的已确认约定。用于延续该文档时参考；其他 TLQ 版本或项目应核对相应资料和用户要求。

## 目录与环境

- 安装基础目录：`/app/tlq`。
- TLQ 安装根目录：`/app/tlq/TLQ8`。
- 在 `setp` 中明确设置 `TLQHOMEDIR=/app/tlq/TLQ8`，在将内容追加至用户环境文件之前完成修改。
- 追加环境设置的命令注明仅执行一次；重新登录后检查环境变量及其预期值。

## 标准与特殊配置

- 标准正文以 TLQ 单产品为主。HUB 及相关 TLQ 关联配置列入特殊场景章节。
- 标准配置模板包含 `MsgSize`，说明用途、单位及调整原则。标准示例值应核对对应版本资料及部署要求。
- 财政场景 `MsgSize=5242880` 字节。明确列出并同步配置相关队列、发送队列及队列模板的适用字段。
- MQ 的消息长度上限按完整消息及实际消息头占用核对。
- `QM_845_EVOUCHER` 是项目名称，作为示例标识；其他队列、连接和实例名同样区分项目值与标准参数。

## 连接及发送读取关系

- 财政方向：行内 TLQ 与财政 TLQ 直接连接。
- 发财政：行内 TLQ 的远程队列经 `SQ_011`、财政发送连接，到财政 TLQ 对应的本地队列。
- 财政返回：财政 TLQ 经 `SQ_845` 发送到行内 TLQ 本地队列 `L.845.330000`，由行内应用读取。
- 人行方向：行内 TLQ ↔ HUB ↔ 行内 MQ ↔ 人行 MQ。
- 发人行：HUB 读取行内 TLQ 本地队列 `R.845.001.330000`，写入行内 MQ 对应远程队列，由行内 MQ 经网络发往人行 MQ。该 TLQ 队列虽以 `R.` 命名，类型仍为本地队列。
- 人行返回：消息经行内 MQ 返回队列，由 HUB 读取并写入行内 TLQ 本地队列 `L.845.330000`，供行内应用读取。
